🚀 QUICKEST PATH TO PRODUCTION (30 minutes)

1. READ SETUP_GUIDE.md (10 min)
   This guide has everything you need to get started.
   It covers: configuration, testing, deployment.

2. COPY .env.example → .env (2 min)
   cp .env.example .env
   Then edit .env with your details (see setup guide for help)

3. CONFIGURE YOUR EMAIL (5 min)
   Get your Gmail App Password from:
   https://myaccount.google.com/apppasswords
   Add it to .env as GMAIL_APP_PASSWORD

4. TEST LOCALLY (3 min)
   python server.py
   (Should start without errors)

5. TEST WITH A REAL ORDER (5 min)
   Visit: http://localhost:3456
   Make test order, verify email received

6. DEPLOY TO RAILWAY (10 min)
   git commit -m "upgrade to multi-channel alert system"
   railway up
   Verify at: https://your-server/health

💡 QUICK TIPS

Getting Gmail App Password?
  1. Go to https://myaccount.google.com/apppasswords
  2. Select "Mail" and your device
  3. Copy the 16-character password
  4. Paste into .env as GMAIL_APP_PASSWORD

Generating Admin API Key?
  openssl rand -base64 32

Want to add Discord/Slack later?
  You can enable webhooks anytime - see SETUP_GUIDE.md

Something not working?
  Check SETUP_GUIDE.md troubleshooting section
  Or QUICK_REFERENCE.md for common issues
